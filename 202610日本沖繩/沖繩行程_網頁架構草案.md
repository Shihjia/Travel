## 一、整體頁面結構(多檔案,GitHub Pages 部署)

**[2026-09-01更新] repo:https://github.com/Shihjia/Travel.git,使用者說明這個repo未來會放所有年度的行程,要能依年度區分。**因此改成「總入口 + 各行程獨立資料夾」的結構,之後每規劃一趟新行程,只要新增一個資料夾+在首頁加一張卡片,不會互相干擾:

```
/ (repo根目錄)
├── index.html              總入口首頁:所有年度/行程卡片列表(依年份分區,例如「2026」底下列出沖繩等行程)
├── assets/
│   ├── style.css           全站共用樣式(頁首/頁尾/卡片/配色等)
│   └── site.js             全站共用邏輯(例:首頁的行程卡片渲染)
└── 2026-okinawa/           本次沖繩行程專屬資料夾
    ├── index.html          沖繩行程總覽頁:6天卡片、班機卡片、飯店卡片、全程地圖(全部景點)
    ├── day1.html ~ day6.html  逐日行程頁:當天時間軸、交通方式、天氣預報區塊、當天地圖(只畫當天路線)
    ├── packing.html        行前準備清單(可勾選)
    ├── style.css           本行程專屬樣式(疊加在共用樣式上,可依行程換主題色)
    ├── script.js           本行程專屬邏輯(地圖、天氣API、清單勾選記憶)
    ├── data/itinerary.js   本行程結構化資料(給地圖/天氣/時間軸共用讀取)
    └── images/             本行程景點照片、封面圖
```

之後新增其他年度行程時,只要照 `2026-okinawa/` 這個模式,建立例如 `2027-xxx/` 資料夾,再到根目錄 `index.html` 補上一張卡片連過去即可,不用動到既有行程的檔案。

## 三、Google地圖打點+分天畫線 — 有一個關鍵技術決定要請您選

您要的效果(每個地點打點、可依天切換/上色畫出路線)技術上有兩條路,差異主要在「是不是Google品牌的地圖」跟「要不要申請金鑰」:

**選項A:Google Maps JavaScript API(真正的Google地圖底圖)**
- 需要您自己用 Google 帳號到 Google Cloud Console(console.cloud.google.com)申請一組免費的 API 金鑰(Google 有給每月 $200 美元額度,像這種個人小型網站用量通常落在免費額度內,但**申請時系統會要求綁定信用卡**才能啟用,即使不會被收費)。
- 申請好金鑰後給我,我把它放進網頁程式碼裡(建議設定「網域限制」只允許您的 GitHub Pages 網址使用這組金鑰,避免被盜用)。
- 優點:是大家最熟悉的 Google 地圖介面、街景/路名資訊最完整。

**選項B:Leaflet.js + OpenStreetMap(開源地圖,完全免費、不用申請任何東西)**
- 外觀跟 Google 地圖不同(是 OpenStreetMap 的底圖樣式),但一樣可以打點、依天分色畫線、點擊地標彈出說明、支援手機縮放拖曳。
- 不用金鑰、不用綁信用卡、不用等審核,馬上可以用,長期也不會有費用疑慮。
- 每個地點的「詳細資訊卡片」依然會附獨立的 Google Maps 連結(點了會另開 Google 地圖 App/網頁,方便實際導航),只是網頁內嵌的底圖本身不是 Google 的。

我的建議是**選項B**,因為不用您額外去申請帳號/綁卡,功能其實一樣完整;但最終決定權在您,兩種我都能做。

## 四、天氣預報 — 有一個時間點的限制要先跟您說明

天氣預報 API(不管哪一家)大多只能查到**未來14-16天內**的預報,現在是9/1,離10/20還有7週多,現在還抓不到實際預報。做法上會是:

- 網頁裡每天的頁面都放一個「天氣」區塊,裡面用 JavaScript 在使用者**打開網頁的當下**,即時去跟天氣API要「這個地點+這個日期」的預報。
- 用的是 Open-Meteo(open-meteo.com)這個免費氣象API,不用申請金鑰、沒有使用量限制,支援指定日期查詢,很適合這種靜態網站。
- 效果是:9月現在打開網頁,天氣區塊會顯示「距離查得到預報還有OO天」之類的提示;等到大約**10月上旬(出發前14-16天內)**之後打開網頁,就會自動顯示當天實際的天氣預報(降雨機率、氣溫)了 — 不用我再回來改網頁,是自動抓即時資料的。
- 加上一個保底:因為沖繩10月還是有機會遇到颱風/雷陣雨,每天行程本來就已經照您先前的規劃原則加了室內備案(水族館、outlet、飯店設施等),天氣區塊也會加一句「若顯示大雨/颱風,請優先考慮OO室內備案」的提醒。
